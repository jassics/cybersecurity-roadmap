# Security Architect Job Descriptions

Representative JDs for Security Architect, Principal Engineer, and Head of Security Architecture roles.

> Companion roadmap: [Security Architect Career Roadmap](../security-architect.md) \u00b7 [Security Architecture Study Plan](https://github.com/jassics/security-study-plan/blob/main/security-architecture-study-plan.md)

---

## 1. Application / Product Security Architect \u2014 Product company

**Role**

You will be the security architecture authority for our product suite, working hand-in-hand with engineering leadership to ship secure-by-default systems.

**Responsibilities**

- Threat-model new products, features, and architectural changes
- Author and maintain security reference architectures for the engineering org
- Chair the security architecture review board (ARB)
- Drive the design of paved roads / secure-by-default platforms and SDKs
- Influence platform decisions: identity, secrets, networking, data, telemetry
- Coach Senior and Staff engineers on security design
- Represent product security in customer trust calls and regulator interactions

**Required**

- 8\u201312 years in security engineering, with 4+ years doing architecture work
- Deep AppSec / Product Security depth + working knowledge of cloud + identity
- Strong threat modeling track record (STRIDE, attack trees, PASTA)
- Excellent technical writing (ADRs, RFCs)
- Experience working cross-functionally with engineering, product, legal, GRC

**Preferred**

- CISSP, CISSP-ISSAP, or SABSA
- Public talks, OSS contributions, conference presence

---

## 2. Cloud Security Architect \u2014 Global SaaS

**Role overview**

You will set the multi-cloud security architecture for our products serving 100M+ users. Most senior IC in the Cloud Security function.

**Responsibilities**

- Define AWS / Azure / GCP reference architectures for identity, networking, data, secrets, detection
- Lead M&A cloud security due diligence
- Set the SCP / Org Policy / Azure Policy ruleset used by 200+ engineering teams
- Drive CSPM + CWPP + CIEM + DSPM \u2192 CNAPP consolidation strategy
- Own technical vendor relationships across cloud security
- Author and review RFCs touching cloud security
- Represent the company externally \u2014 conferences, customer trust calls

**Required**

- 10+ years in security, with 6+ years architecting cloud security at scale
- Deep expertise in at least two of AWS / Azure / GCP at the architecture level
- Strong opinions on cloud-native vs third-party tooling, with the receipts to back them
- Excellent communication; can move exec opinion based on technical merit
- Track record of mentoring senior engineers

**Preferred**

- Multiple cloud security certs (AWS Security Specialty, AZ-500, GCP PCSE, CCSP)
- Public conference talks (re:Invent, RSAC, fwd:cloudsec, Black Hat)
- OSS maintainership

---

## 3. Zero Trust / Identity (IAM) Architect \u2014 BFSI

**Description**

You will lead the design of the bank's Zero Trust + Identity strategy across workforce, customer, and workload identity.

**Responsibilities**

- Set the Zero Trust roadmap aligned to NIST SP 800-207
- Architect the IAM platform: SSO, MFA, IGA, PAM, JIT access, CIAM
- Design workload identity using SPIFFE/SPIRE or cloud-native equivalents
- Drive deprecation of legacy VPNs in favor of ZTNA / SSE / SASE
- Lead identity-related regulatory engagement (RBI, SEBI, DORA-equivalent for foreign subs)
- Mentor IAM engineers across multiple business units

**Required**

- 10+ years total, with 5+ in identity / IAM
- Deep knowledge of OIDC, OAuth 2.0 + PKCE, SAML, SCIM, FIDO2 / WebAuthn, mTLS
- Experience with Okta / Entra ID / Ping / SailPoint / CyberArk / Saviynt
- Familiarity with NIST SP 800-207 and CISA Zero Trust Maturity Model
- Strong executive communication

---

## 4. Enterprise / Chief Security Architect \u2014 Large enterprise

**Role**

Most senior individual contributor in the Security org. Owns the multi-year enterprise security architecture across cloud + on-prem + hybrid, workforce + workload + customer identity, and all major regulatory regimes.

**Responsibilities**

- Set and evolve the enterprise reference architecture
- Lead M&A diligence + integration playbooks
- Set the bar for new platform / vendor decisions
- Be the technical interviewer for senior+ hires
- Externally represent the org \u2014 conferences, regulator forums, customer briefings
- Coach Director-level and Distinguished Engineer-track ICs

**Required**

- 12\u201318+ years in security, with 6+ in architecture leadership
- Public technical reputation in at least one domain
- Multiple senior certifications (CISSP + ISSAP or SABSA strongly preferred)
- Demonstrated ability to influence at the CTO / CIO / Board level

---

## 5. AI Security Architect \u2014 Emerging (BigTech / Frontier lab)

**Role**

You will set the architecture for how the company ships AI products securely at scale.

**Responsibilities**

- Define the reference architecture for **secure agentic systems**: tool authorization, sandboxing, supervision, attestation
- Set the LLM gateway architecture (auth, logging, content filtering, DLP, prompt observability)
- Establish AI bill of materials (AI-BOM), model signing, and supply-chain controls for weights
- Lead industry-shaping research; engage standards bodies (NIST, ISO/IEC SC 42, OWASP, MITRE)
- Coach senior AI security engineers; chair the AI architecture review board

**Required**

- 10+ years in security, with 3\u20136 years deep in AI/ML security
- Public technical reputation (papers, talks, OSS) in AI security
- Strong systems design background
- Deep understanding of LLM architecture, alignment, agent frameworks, and adversarial ML
- Excellent technical writing

## What recruiters search for

- **Frameworks**: NIST CSF 2.0, NIST 800-53, NIST SP 800-207 (Zero Trust), NIST SSDF (800-218), NIST AI RMF, ISO 27001 / 27002, ISO/IEC 42001, OWASP SAMM / ASVS / BSIMM, CIS Controls v8, SLSA, SOC 2, PCI-DSS 4.0, HITRUST, FedRAMP, DORA
- **Modeling**: STRIDE, attack trees, PASTA, LINDDUN, MITRE ATT&CK (Enterprise / Cloud / Mobile / ICS), MITRE ATLAS
- **Patterns**: Zero Trust, BeyondCorp, Defense in Depth, Secure-by-Design (CISA), shift-left, paved roads, cryptographic agility, PQC readiness
- **Certs**: CISSP, CISSP-ISSAP, SABSA, TOGAF, CCSP, AWS Solutions Architect Pro + Security Specialty, Azure SC-100, GCP PCSE, CISM, CRISC, ISO 27001 LA/LI
- **Documents you write**: ADRs, RFCs, threat models, design reviews, security architecture white papers
