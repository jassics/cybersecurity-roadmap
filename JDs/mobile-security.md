# Mobile Security Job Descriptions

Representative Mobile App Security, Pentesting, and Engineering JDs.

> Companion roadmap: [Mobile Security Career Roadmap](../mobile-security.md) \u00b7 [Mobile App Security Study Plan](https://github.com/jassics/security-study-plan/blob/main/mobile-application-security-study-plan.md)

## 1. Junior Mobile Penetration Tester \u2014 Pentest consulting firm

**Responsibilities**

- Conduct mobile application penetration tests against Android and iOS apps for enterprise clients
- Perform static + dynamic analysis using MobSF, jadx, apktool, Frida, objection, class-dump
- Identify and report issues per OWASP MASVS / MASTG
- Write client-ready reports with clear reproduction steps and risk ratings
- Defend findings on remediation calls with client engineers

**Required**

- 1\u20132 years in security or mobile development
- Working knowledge of OWASP Mobile Top 10
- Hands-on with Burp Suite, Frida, MobSF
- Comfort with Java / Kotlin (Android) or Objective-C / Swift (iOS)
- Strong written English

**Nice to have**

- eMAPT or TCM Mobile cert
- Bug bounty mobile track record

---

## 2. Mobile Security Engineer (Mid) \u2014 Fintech / Banking app

**Responsibilities**

- Own mobile security for our 50M+ user Android + iOS apps
- Run mobile threat modeling for every major feature pre-launch
- Operate and tune anti-fraud / RASP (Promon, Appdome, GuardSquare) integrations
- Build mobile DAST / SAST into the CI pipeline (MobSF, AppSweep, NowSecure)
- Lead bypass-resilience testing \u2014 root / jailbreak detection, SSL pinning, emulator detection
- Coordinate Play Integrity / App Attest rollouts and remediations
- Partner with the backend AppSec team on the mobile \u2192 API attack surface

**Required**

- 3\u20135 years in mobile security or mobile development with security focus
- Strong reverse engineering of Android (jadx + Ghidra) and iOS (Hopper / Ghidra) binaries
- Deep Frida / objection skills
- Solid web/API security background (OWASP Top 10, API Top 10)
- Familiarity with Play Integrity API, Apple DeviceCheck / App Attest

**Preferred**

- OSWE, eWPTXv2
- Experience with cross-platform frameworks (React Native, Flutter)
- Public talks or research

---

## 3. Senior Mobile Security Engineer / Mobile Security Architect

**Responsibilities**

- Set the multi-year mobile security strategy across Android + iOS
- Define secure-by-default SDK patterns for internal mobile developers
- Design the anti-fraud architecture (attestation, behavioral, device fingerprinting)
- Lead app store impersonation / cloned-app takedown program
- Drive the mobile bug bounty program
- Mentor mobile security engineers; hire and grow the team

**Required**

- 7\u201310+ years in security, with 4+ years deep in mobile
- Demonstrated ability to design platform-level mobile security controls
- Public reputation (talks, OSS, blog posts) preferred
- Excellent communication with product, engineering, and risk

## What recruiters search for

- **Tools**: Burp Suite + mobile assistant, MobSF, jadx, apktool, Drozer, Frida, objection, class-dump, Hopper, Ghidra, IDA Pro, radare2, Cycript (legacy), Sideloadly, AppSweep, NowSecure, Data Theorem, Ostorlab, Quokka.io
- **Anti-tamper / RASP**: GuardSquare DexGuard / iXGuard, Promon Shield, Appdome, V-Key, Approov
- **Cross-platform**: React Native, Flutter, Xamarin, Unity (IL2CPP), Cordova, Ionic, Capacitor
- **Concepts**: OWASP MASVS / MASTG, OWASP Mobile Top 10, Play Integrity API, App Attest, DeviceCheck, certificate pinning, mTLS, deep link / Universal Link / App Link abuse, JNI security
- **Certs**: eMAPT, eWPTX, OSCP / OSWE, Mobile Hacking Lab Practitioner, 8kSec Offensive Mobile
