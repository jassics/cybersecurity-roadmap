# Security Job Roles and Career Progression

This page maps out the **most common cybersecurity job roles**, grouped by domain, and shows how someone can **progress, specialize, or pivot** from one role to another.

> Note: CXO/Board level roles (CISO, CSO, vCISO) are intentionally kept brief. The focus is on individual contributor (IC) and engineering management tracks that you can actively target from job portals like LinkedIn, Naukri, Indeed.

## How to use this page
1. Pick the **domain** that interests you (AppSec, Cloud, Network, SOC, GRC, etc.).
2. Identify your **current level** (Entry / Mid / Senior / Lead).
3. Look at the **next 1–2 roles** above and the **lateral pivots** to plan your learning.
4. Open the **linked domain page** for skill-by-skill roadmap, tools, and certifications.

## Career levels (rough YoE guideline)
| Level | Years of Experience | Typical Titles |
|-------|---------------------|----------------|
| Entry | 0–2 | Intern, Analyst, Associate Engineer, Junior Pentester |
| Mid | 2–5 | Security Engineer, Senior Analyst, Consultant |
| Senior | 5–8 | Senior Security Engineer, Lead Pentester, Senior Consultant |
| Staff / Principal | 8–12 | Staff Engineer, Principal Engineer, Security Architect |
| Leadership | 10+ | Security Manager, Director, Head of Security, CISO |

> YoE is only a rough guideline. Skill depth, business impact, and domain expertise matter more than years.

## 1. Application / Product Security
Often a blend of AppSec + CloudSec + a little DevSecOps. Strong code reading skills required.

**Career ladder**
1. AppSec Intern / Security Analyst (Entry)
2. Application Security Engineer (Mid)
3. Senior Application Security Engineer / Product Security Engineer (Senior)
4. Staff / Principal Product Security Engineer (Staff)
5. Application Security Architect / Head of Product Security (Lead)

**Lateral pivots from AppSec**
- → DevSecOps Engineer (automation focus)
- → Cloud Security Engineer (infra focus)
- → Offensive Security / Red Team (exploitation focus)
- → Security Architect (design focus)

See: [Web Security Roadmap](web-security.md) · [API Security Roadmap](api-security.md) · [Software Security Roadmap](software-security.md)

---

## 2. Offensive Security / Penetration Testing
Hands-on hacking — networks, web, mobile, cloud, hardware, social engineering.

**Career ladder**
1. Junior Penetration Tester / VAPT Analyst (Entry)
2. Penetration Tester / Red Team Operator (Mid)
3. Senior Penetration Tester / Lead Red Teamer (Senior)
4. Principal Offensive Security Engineer / Red Team Lead (Staff)
5. Director of Offensive Security / Head of Red Team (Lead)

**Specializations**
- Web/API Pentester · Mobile Pentester · Cloud Pentester · ICS/OT Pentester · Hardware/IoT · Adversary Emulation · Bug Bounty Hunter

**Lateral pivots**
- → Application Security Engineer
- → Threat Hunter / Detection Engineer (Blue Team)
- → Security Researcher / Exploit Developer

---

## 3. SOC / Blue Team / Detection & Response
Defensive operations — SIEM, EDR/XDR, incident response, threat hunting.

**Career ladder**
1. SOC Analyst L1 (Entry) — alert triage
2. SOC Analyst L2 / Incident Responder (Mid) — investigation
3. SOC Analyst L3 / Threat Hunter / Detection Engineer (Senior)
4. SOC Architect / Principal Detection Engineer (Staff)
5. SOC Manager / Director of Security Operations (Lead)

**Lateral pivots**
- → DFIR (Digital Forensics & Incident Response)
- → Threat Intelligence Analyst
- → Purple Team / Adversary Emulation
- → Detection Engineering → DevSecOps (automation)

See: [SOC / Blue Team Career Roadmap](soc-blue-team.md)

---

## 4. Cloud Security
The fastest growing branch. Heavy overlap with DevSecOps and AppSec.

**Career ladder**
1. Cloud Security Analyst (Entry)
2. Cloud Security Engineer (Mid)
3. Senior Cloud Security Engineer / CSPM Engineer (Senior)
4. Cloud Security Architect / Principal Cloud Security Engineer (Staff)
5. Head of Cloud Security (Lead)

**Specializations**
- AWS / Azure / GCP Security Specialist · CSPM/CNAPP Engineer · Cloud IAM Engineer · Cloud Detection & Response · Multi-cloud Security Architect

**Lateral pivots**
- → DevSecOps Engineer
- → Container/Kubernetes Security Engineer
- → SRE with Security focus

See: [Cloud Security Roadmap](cloud-security.md)

---

## 5. DevSecOps / Security Automation
Bridge between security and engineering. Code-heavy, pipeline-heavy.

**Career ladder**
1. DevSecOps Associate / Security Automation Engineer (Entry)
2. DevSecOps Engineer (Mid)
3. Senior DevSecOps Engineer (Senior)
4. Principal DevSecOps Engineer / Platform Security Engineer (Staff)
5. Head of DevSecOps / Engineering Manager - Security Platform (Lead)

**Lateral pivots**
- → Cloud Security Engineer
- → Application Security Engineer
- → Site Reliability / Platform Engineer
- → Supply Chain Security Engineer

See: [DevSecOps Roadmap](devsecops.md)

---

## 6. Network Security
Traditional but evergreen. Strong base for cloud network security and zero trust.

**Career ladder**
1. Network Security Analyst / NOC Analyst (Entry)
2. Network Security Engineer / Firewall Engineer (Mid)
3. Senior Network Security Engineer (Senior)
4. Network Security Architect / Zero Trust Architect (Staff)
5. Head of Network Security (Lead)

**Specializations**
- Firewall (Palo Alto, Fortinet, Check Point) · SD-WAN/SASE · Zero Trust · VPN/NAC · Network Forensics · Wireless Security

**Lateral pivots**
- → Cloud Network Security (AWS VPC, Azure VNet, GCP VPC)
- → SOC / Detection Engineer
- → Penetration Tester (Network)

See: [Network Security Roadmap](network-security.md)

---

## 7. Container / Kubernetes Security
A modern niche. Usually grown into from Cloud Security or DevSecOps.

**Career ladder**
1. Container Security Analyst (Entry, rare title)
2. Container / Kubernetes Security Engineer (Mid)
3. Senior K8s Security Engineer (Senior)
4. Principal Cloud-Native Security Engineer (Staff)

**Lateral pivots**
- → Cloud Security Architect
- → DevSecOps Lead
- → Platform Security Engineer

See: [Container Security Roadmap](container-security.md)

## 8. GRC (Governance, Risk & Compliance)
Less code, more policy, audit, and risk language. Critical for regulated industries.

**Career ladder**
1. GRC Analyst / Compliance Analyst (Entry)
2. Risk Analyst / IT Auditor / ISO/SOC2 Consultant (Mid)
3. Senior GRC Manager / Risk Manager (Senior)
4. GRC Lead / Compliance Architect (Staff)
5. Head of GRC / Director Risk / CISO track (Lead)

**Specializations**
- Privacy (GDPR, DPDP, CCPA) → DPO track · ISO 27001 / SOC 2 Auditor · PCI-DSS QSA · HITRUST · TPRM (Third Party Risk) · AI Governance

**Lateral pivots**
- → Security Awareness & Training
- → vCISO / CISO advisory
- → Privacy Engineer (technical + GRC hybrid)

See: [GRC & Privacy Career Roadmap](grc-privacy.md)

## 9. Security Architecture & Leadership
Senior IC + leadership track that designs systems, threat models, security strategy, and grows into Head of Security / CISO roles.

**Roles**
- Security Architect (domain-agnostic)
- Application / Cloud / Network / Enterprise Security Architect
- Zero Trust Architect
- Identity (IAM) Architect
- Principal / Distinguished Security Engineer
- Director of Security Architecture
- Deputy CISO → CISO / vCISO

> Usually reached after 8+ years of strong technical depth in 1–2 domains.

See: [Security Architecture & Leadership Career Roadmap](security-architect.md) · [Security Architecture Study Plan](https://github.com/jassics/security-study-plan/blob/main/security-architecture-study-plan.md)

## 10. Identity & Access Management (IAM)
Often invisible but business critical. Strong career growth across cloud and SaaS era.

**Career ladder**
1. IAM Analyst / IAM Engineer (Entry)
2. IAM Engineer (Okta, Azure AD, Ping, SailPoint, CyberArk) (Mid)
3. Senior IAM Engineer / PAM Engineer (Senior)
4. IAM Architect (Staff)

**Lateral pivots**
- → Cloud Security (IAM focus)
- → Zero Trust Architect
- → Identity Governance / GRC

See: [Identity & Access Management Career Roadmap](iam-security.md) · [IAM Study Plan](https://github.com/jassics/security-study-plan/blob/main/iam-security-study-plan.md)

## 10b. Cryptography Engineering
Small, math-flavored, deeply technical, well-paid niche. Most enter from AppSec / backend.

**Career ladder**
1. Junior Cryptography / Applied Security Engineer (Entry, often via AppSec)
2. Cryptography Engineer (Mid)
3. Senior Cryptography Engineer (Senior)
4. Principal / Distinguished Cryptography Engineer (Staff)
5. Cryptographer / Cryptanalyst (PhD-track research)

**Specializations**
- Post-Quantum Cryptography (PQC) migration
- Confidential Computing (SGX / SEV-SNP / TDX / Nitro Enclaves)
- Privacy Engineering (PETs, FHE, MPC, ZK proofs)
- Blockchain / Web3 cryptography (TSS, MPC wallets, BLS)

See: [Cryptography Engineering Career Roadmap](cryptography-engineering.md)

---

## 11. Threat Intelligence & Research
For folks who love OSINT, reverse engineering, and writing reports.

**Roles**
- Threat Intelligence Analyst (Entry → Senior)
- Malware Analyst / Reverse Engineer
- Security Researcher (often paired with exploit dev / vuln research)
- CTI Lead / Manager

**Lateral pivots**
- → DFIR
- → Red Team / Adversary Emulation
- → Detection Engineering

## Engineering Manager track vs. Individual Contributor track
At Senior+ level, most folks face a fork:

- **IC Track**: Staff Engineer → Principal Engineer → Distinguished Engineer / Security Architect. Stay technical.
- **Management Track**: Security Manager → Director → VP Security → CISO. People + strategy.

Both are valid. Many companies (esp. product orgs) pay them equally up to Director level.
